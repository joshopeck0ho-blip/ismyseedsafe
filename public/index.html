Technical architecture & security

Independent security methodology

Our assessment framework operates under strict zero-knowledge principles. We believe privacy tools must never ask for trust when they can offer mathematical guarantees.

1. Client-side only execution

All character parsing, BIP-39 word index mapping, and entropy calculation occur exclusively inside your browser's local JavaScript engine.

2. Offline entropy pattern matching

Seeds are cross-analyzed against local dictionary patterns, repeating index anomalies, known duplicate sequences, and weakness signatures.

3. Immediate in-memory wipe

Closing or resetting the tool triggers an immediate garbage collection sweep that completely overwrites input variables in DOM memory.

Verification: You can disconnect your device from WiFi/Ethernet before clicking "Check my seed". The assessment functions 100% offline.
